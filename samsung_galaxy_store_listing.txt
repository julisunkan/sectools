FULL DESCRIPTION
----------------------------------------------------------------
NetSec Toolkit is the most complete mobile cybersecurity companion available on Android. Designed for security professionals, ethical hackers, IT administrators, students, and privacy-conscious users, it puts 100 fully functional security tools into one clean, fast, offline-capable app.

Whether you are auditing your home network, analyzing SSL certificates, cracking open a suspicious JWT token, searching CVE databases, or managing your encrypted passwords, NetSec Toolkit has the tool for the job. No ads. No subscriptions. No root required.

NETWORK TOOLS

1. Scan your local network and discover every connected device with IP and MAC addresses.
2. Analyze nearby Wi-Fi networks for security weaknesses, encryption standards, and signal strength.
3. Look up any IP address for geolocation, ISP, and ASN data.
4. Run ping tests to check host reachability and measure latency.
5. Trace the full route of your packets across the internet hop by hop.
6. Scan TCP and UDP ports to identify open services on any host.
7. View your ARP table and monitor active devices on your LAN.
8. Identify the manufacturer of any device by its MAC address.
9. Monitor bandwidth usage and track network latency history over time.

PRIVACY AND DESIGN

NetSec Toolkit stores all data locally in an encrypted SQLite database. There is no account, no cloud sync, no telemetry, and no background data collection of any kind. The app works fully offline for all tools that do not require external API calls. Optional API integrations with services such as VirusTotal, AbuseIPDB, Have I Been Pwned, and AlienVault OTX can be configured in Settings using your own API keys. The app uses a dark cybersecurity-themed interface optimized for readability and extended professional use sessions.
